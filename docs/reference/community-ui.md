# 社区扩展 UI 参考

本页只记**现行交互行为**。基础视觉令牌、主题与动效见 [UI/动效规范](ui-motion.md)；测试执行入口见 [CI](../development/ci.md)。不以 PR 编号、临时研究笔记或一次截图作为长期规范。

## 共用组件

- Lumi、Material 3、Liquid Glass 共享业务状态与布局；复用 `AppColors`、`AppType`、`AppSpace`、`AppRadius` 和已存在的 `GroupedCard`、`AppBottomSheet`、`AppSheetHeader`、`LiquidGlassAlertDialog`。
- 新增可交互元素应提供不小于 48×48dp 的有效触控目标，允许大字号增高与换行；操作状态、已选中状态和错误需有语义/反馈。降低动效和电子墨水模式有安全回退。
- 破坏性、不可逆的数据库操作二次确认；进行中的操作不重复提交。关闭弹窗不意味着继续向前导航。

## 标签与分组

- 使用 `TagManagementRepository` 和现有 Room/DAO，不创建第二份标签存储。
- “未分组”始终可见。重命名只改组名；删除组仅解除分组，不删标签、书籍或标注。删除标签必须说明影响范围并单独确认。
- 批量选择先维护本地选择集，保存时再写数据库；同步或并发更新后清理失效的键。列表量大时采用懒加载，保留组内连续 `GroupedCard` 的视觉语义。
- 空名、重复名称、失败写入保留编辑状态并展示错误，不乐观删除。

## 本地阅读日志与分享

- `ReadingJournalRepository` / `ReadingJournalRecorder` 记录用户明确同意后启用的本地阅读事件。默认关闭，停止不删除历史，清除需额外确认且不能删除书籍、进度和笔记。
- 保留期限调整可能立即删除过期日志，应向用户说明；停止/清除后的异步任务不得复活旧事件。
- 分享使用现有 `BookShareActivity`，不添加第三方服务器、遥测或云端海报服务。

## TXT/Markdown 导出

- 复用 `BookNotesExportBuilder`，单书/跨书导出都尊重当前筛选条件，排除隐藏内容。
- 用户选择格式后，Android SAF 明确选择目标文件；取消不写入，失败可重试，重复点击不可创建多次导出。
- Markdown 保留原文换行并转义 Markdown 控制字符和可能触发 HTML 的输入，不上传笔记。

## 回归重点

| 场景 | 不变量 |
| --- | --- |
| 三主题、e-ink、降低动效 | 功能和操作语义一致，必要时关闭透明/动画效果 |
| 大字体、窄屏、横屏、RTL、TalkBack | 不裁切关键操作，语义、焦点与确认路径可访问 |
| 标签分组删除、批量修改 | 删除组不删标签；删除标签前确认 |
| 日志开关、保留期限与清空 | 不会在用户撤销同意后重新生成事件 |
| 筛选导出、隐藏书、SAF 取消 | 无隐藏数据外泄、无未授权写入 |

自动化和 PR 模拟器任务负责基本回归；不能把未进行的真机验证写成已完成。具体证据附到 PR 或 GitHub Actions，不追加到此文档。
