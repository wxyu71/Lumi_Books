### 更新日志

## 2.3.12-beta.1 · Lumi Community
· 基于 Lumi 2.3.11 的公开源码建立独立的社区 Beta 版本，应用与原版可同时安装。
· 移除设置中的官方 QQ 群和旧问题反馈入口，GitHub 仓库与讨论入口改为社区 Fork。
· 优化首次进入流程，保留必要的本地隐私和使用说明，点击同意后即可进入，无倒计时或强制功能介绍。
· 移除启动时访问上游远程更新及公告配置的行为，取消旧版捐赠兑换宣传。
· 将可选的赞助入口收纳到关于应用页面，保留原作者署名和许可证信息。
· 提供本地书籍/标注标签管理，支持分组创建、重命名、删除、批量移动与删除；操作复用现有数据层且不绑定会员。
· 取消桌面小组件系统注册，不提供官方阅读报告及高级摘录模板。
· 增加 Android GitHub Actions Beta 构建、APK 校验、单元测试与静态社区规范检查。
· 增加上游自动检查与待审查 PR 工作流，需合并到默认分支并授权 Actions 创建 PR 后生效。
· 新增默认关闭的阅读日志、保留期限和确认清除；复用公开的阅读签到海报预览及系统分享。
· 增加单书和跨书筛选标注的 Markdown（.md）导出，保留 TXT 并由系统文件选择器确定保存路径。
· 说明：Beta 使用 CI Debug 签名；新功能仍须通过最新 CI 单元测试及真机验收。
